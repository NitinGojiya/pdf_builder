# 📄 pdfbuilder

A Ruby on Rails application for building and managing PDFs.
**Version**: `black`

---

## 🚀 Getting Started

### 🔧 Requirements

- Ruby `3.4.2`
- Rails `8.0.0`
- PostgreSQL
- Git

---

### 📥 Cloning the Repository

```bash
git clone https://github.com/NitinGojiya/pdf_builder.git
cd pdf_builder
```

---

### ⚙️ Installation

```bash
bundle install
```

---

### 🗃️ Database Setup

```bash
rails db:create
rails db:migrate
rails db:seed # optional
```

---

### 🧰 Services Used

- PostgreSQL (Database)
